# Regression Checklist EduLock Siswa

Checklist ini dipakai agar perubahan baru di **EduLock siswa** tidak merusak fitur izin, proteksi, dan monitoring yang lama.

## Aturan Pakai
- Pilih item sesuai area yang benar-benar berubah.
- Jika edit file bersama di `src/main`, mulai dari asumsi bahwa alur siswa secara luas ikut berisiko terdampak.
- Hasil uji ringkas wajib ditulis di [BUILD_LOG.md](./BUILD_LOG.md).
- **Jangan campur uji `internet offline` dengan uji `GPS mati` dengan uji `Mode Pesawat`.** Ketiganya punya aturan operasional BERBEDA setelah perubahan Fase 1 Revisi 2026-09-03.
- Untuk roadmap hybrid saat ini, acuan mode **TELAH BERUBAH** menjadi **Hybrid Fase 1 Revisi (Hapus Offline Fail-safe)** (menggantikan "Hybrid Konservatif"):
  - payload lokal aktif dipakai sebagai fondasi offline-first,
  - **fail-safe internet offline > 2 menit saat jam sekolah SEKARANG DIHAPUS TOTAL** sesuai keputusan user (tidak ada lagi toast countdown / overlay merah offline),
  - **Mode Pesawat (AIRPLANE_MODE_ON)** tetap harus trigger lockdown seperti biasa (jalur terpisah dari offline biasa),
  - sedangkan **GPS mati** harus lewat jalur overlay recovery lokasi, bukan dianggap sama dengan internet offline.
